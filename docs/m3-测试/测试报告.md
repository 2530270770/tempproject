# 测试报告

## 1. 环境与可复现命令

测试使用 Python 标准库 `unittest`，覆盖率使用标准库 `trace`，不依赖第三方测试框架或 CI Runner。

```powershell
python --version
python -m unittest discover -s tests -p "test_*.py" -v
python tests\coverage_report.py
python -m unittest tests.test_reporting_cli.ReportingAndCliTests.test_100_fr_300_tc_performance_budget -v
python -m src check . --output-dir <独立输出目录> --team-id T13
```

以下命令均在仓库根目录（包含 `README.md` 的目录）执行。本次执行日期为 2026-11-10，环境为 Windows PowerShell、Python 3.14.6。

## 4. 项目自检与标准样例验收

项目自检命令输出为：

```text
requirements: 14 total / 14 covered
tests: 21 total
coverage.fr: 1.0
coverage.critical_boundary: 1.0
coverage.critical_happy: 1.0
issues: 0
```

21 条 TC 分别存放在 `tests/TC-01.md` 至 `tests/TC-21.md`，每个文件一条用例。

内置 good 测试夹具实测 0 个 issue。标准样例验收直接读取老师提供的**完整标准仓库目录**。以下命令均在仓库根目录执行，报告写到临时目录：

```powershell
python -X utf8 -m src check `
  "..\要求\⑥标准样例仓库（修正版）v1.2\team-99" `
  --output-dir "$env:TEMP\T13-m3-standard" `
  --team-id G99

python -X utf8 -m src check `
  "..\要求\埋雷样板仓库（bad·m3发学生）\bad-repo-team-99" `
  --output-dir "$env:TEMP\T13-m3-bad" `
  --team-id G99
```

两次命令的关键输出均为：

```text
requirements.total = 6
requirements.covered = 0
requirements.uncovered = FR-01、FR-02、FR-03、FR-04、FR-05、FR-06
requirements.critical_missing_boundary = FR-02
requirements.critical_missing_happy = FR-02
tests.total = 5
tests.orphan = TC-22
issues = 9
```

两份完整目录中与 B 相关的 `docs/m1-立项与需求/SRS.md` 和 `tests/` 采用项目符号式 FR、标题式 TC，二者均报出：

- `MISSING_TEST`：`FR-05` 没有 PASS 用例，证据定位到 `SRS.md`。
- `CRITICAL_NO_BOUNDARY`：关键需求 `FR-02` 缺少 PASS 边界用例，证据定位到 `SRS.md`。
- `ORPHAN_TEST`：`TC-22` 的 `covers: FR-99` 指向不存在的需求，证据定位到 TC 文件。

教师样例 TC 没有填写 `实际结果`，因此严格按 UNKNOWN 处理，而不是推断为 PASS。系统除必须命中的 R3、R4 外，还会报告 FR-01 至 FR-06 的漏测以及 FR-02 缺正常 PASS 用例；这些是样例数据本身的覆盖缺口。

## 5. 变更回归

使用单元测试中的基线版与当前版 SRS 夹具执行差异检查后，系统识别：

- `changed_fr=FR-01,FR-02`；
- `affected_tests=TC-01,TC-02`；
- `pending=TC-01,TC-02`；
- 回归状态为 `NEED_REGRESSION`；
- 删除的 `FR-02` 仍可由基线索引定位，当前 `TC-02` 保持可见，不会被静默消失。

项目自身相对 M2 基线的复现命令：

```powershell
python -X utf8 -m src check . `
  --baseline-ref m2-architecture `
  --output-dir "$env:TEMP\T13-m3-regression" `
  --team-id T13
```

预期：`changed_fr=FR-14`，`affected_tests=TC-20、TC-21`，`pending=[]`，回归状态为 `CLOSED`。报告中可能保留一条 LOW 级 `NEED_REGRESSION`，用于说明 FR-14 已变更且关联用例已完成 v2 回归。
