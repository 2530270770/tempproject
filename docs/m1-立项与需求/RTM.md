## 双向核查口径

- 正向：每条 FR 至少有一个 `实际结果: PASS` 的 TC。
- 反向：每条 TC 的所有 `covers` 都必须引用当前存在的 FR。
- 关键需求：至少一个 PASS 正常用例和一个 PASS 边界用例。
- 变更：受影响 TC 的验证版本必须追上当前 SRS 版本，才视为回归闭环。
- 覆盖统计：输出 FR 覆盖率以及关键 FR 正常/边界覆盖率，并与覆盖/未覆盖/孤儿/重复矩阵保持一致。
- AI 初抽：候选追溯关系在人工确认前标为“待人工确认”，不计入覆盖率、差异结论或正式双向 RTM。
